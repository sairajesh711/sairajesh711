### 💡 How I approach AI products
- **AI has to earn its place.** I use a model only where it clearly beats the simpler option, and I prove it before anyone relies on it.
- **People own the decisions that matter.** Numbers come from logic you can test, AI explains them, and a person signs off.
- **Productive and efficient.** More output for fewer tokens and lower running costs. A tool nobody can afford to keep running isn't a product.
